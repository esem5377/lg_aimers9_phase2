# 작업 로그 (2026-08-20 ~ 2026-08-21)

기준선: es_ws v7(`submit_v7_catboost_calibrated_rawid`) = **974.9점**, 팀 전체 최고. 이번 세션에서 시도한 모든 실험은 이 값을 기준으로 비교.

## 1. 검증 인프라: GroupKFold(투수 기준) 2번째 축 확보
`season==2024` 단일 홀드아웃(fold0/fold2 일치 기준 포함)이 freq974 실험(8/20 이전 기록)에서 이중 통과하고도 실제 리더보드에서 반증된 전례가 있어, `StratifiedGroupKFold(group=pitcher_id, n_splits=5)`로 "미본 투수 일반화" 축을 별도로 구축.
- 결과(974 레시피, iterations=1000): AUC 0.5711±0.0032, BSS calibrated 1719.67±100.78. fold 간 안정적, season 기반 검증에서 반복된 "2023 폴드 붕괴" 없음.
- Platt 보정이 이 축에서는 거의 무의미(델타 +0.6) — season 분할과 대조적.
- 이후 대부분의 실험에서는 시간 문제로 이 축을 스킵하고 season 기반 진단만 사용(사용자 요청).

## 2. `pitch_control_future_roadmap.md` 검토
외부(추정) 로드맵 문서를 실제 실험 이력과 대조. 최우선순위였던 "Season Recency Weighting"과 "Raw ID 빈도 피처"는 이미 8/19~8/20에 시도·기각된 것으로 확인. 유효하다고 판단한 두 아이디어(Dual Validation, Prediction Correlation 게이팅 앙상블) 중 Dual Validation만 위 1번으로 채택, 상관 게이팅은 이질적 후보 모델이 없어 보류.

## 3. 선수별(pitcher_id) 잔차 후처리 보정 — 기각 (제출 전 로컬에서 걸러짐)

## 5. 목표 상향: 974.9가 아니라 1150점(타 팀 리더보드 기준) 확인
사용자가 다른 참가팀 순위 기준 1150점을 목표로 제시. 격차(+175)가 지금까지 단일 실험 규모(±5~50)의 3배 이상이라 "완전히 다른 접근"으로 전환해 5갈래 시도:

1. **DeepFM 임베딩** — 예전 세션 자산(`deepfm_cv.py`/`cv5_emb_catboost.py`) 재확인. GroupKFold OOF에서 이미 악화 확인(임베딩 추가 시 AUC 0.5712→0.5657, 5-fold 전부 마이너스). 실제 제출 안 함.
2. **팀 매핑**(trackman의 실제 KBO 팀 코드 ↔ train의 익명 team_id) — 시즌×월 등장 패턴 상관계수로 확인했으나 모든 후보가 0.87~0.98에 뭉쳐 마진 0.001~0.006 수준으로 사실상 구분 불가. **시도 자체 포기**.
3. **LGBM/XGBoost 앙상블 재검증**(현재 974 레시피 기준) — CatBoost 833.08 vs LGBM 754.98 vs XGBoost 719.50, 블렌드 최적(cat 0.85:lgb 0.05:xgb 0.1)도 +2.90뿐. 8/18 결론("앙상블 기여 미미") 재확인. 실제 제출 안 함.
4. **trackman METRIC_COLS 4→8개 확장**(extension/rel_height/rel_side/zone_speed 신규, 1%/99% winsorize) — 로컬 +20.81 → **실제 제출 960점(-14.9)**.
5. **trackman_context 4번째 독립 축 추가**(`game_month`, 저온기 그립감 저하 도메인 가설) — 로컬 +18.39 → **실제 제출 956점(-18.9)**.
