# 작업 로그 (2026-08-21, 이전 세션 재개분)

기준선: 974.9점(es_ws v7). 8/21 앞부분 세션(GRU 설계안/Optuna BSS 탐색/매치업 피처, 전부 막힘)에 이어 재개.

## 1. 정규화 강화 가설 — 기각, 세 축 전부 뚜렷하게 악화
"regime shift 상황에서는 강하게 정규화된 모델이 더 잘 버틸 것"이라는, 8/21 앞부분 세션에서 논의만 하고 미착수였던 가설을 처음 시험. 974 레시피 그대로, baseline(depth=8, l2=20, bagging_temp=1, random_strength=1) vs reg_strong(depth=5, l2=50, bagging_temp=2.5, random_strength=5) 비교.
- 결과(calibrated BSS, baseline→reg_strong): fold0(→2022) -97.33, fold2(→2024) -117.06, GroupKFold(3-fold 평균) -167.69. **세 축 전부 뚜렷하게 악화**, AUC도 동반 하락.
- 8/21 앞부분의 Optuna 탐색(30 trial, fold0/fold2 동시 개선 조합 0개)과 같은 결론을 다른 방법으로 재확인. 실제 제출 없이 로컬에서 기각.

## 2. 시드 배깅(seed-averaging bagging) — 실제 제출로 **979점, 새 팀 최고**
다른 모든 "앙상블"(LGBM/XGBoost 이종 모델, D=분류기+회귀기)과 달리, 완전히 동일한 974 레시피를 랜덤시드만 바꿔(42/7/123) 3번 학습해 raw 확률을 평균낸 뒤 Platt 1회 fit — 새 정보 추가 없이 순수 분산 감소.
- 로컬 검증(fold0/fold2, iterations=1000, GroupKFold는 사용자 요청으로 시간상 스킵): fold0 단일시드평균 2386.50(std=1.85)→배깅 2390.84(+4.34), fold2 832.63(std=2.28)→836.60(+3.98). 두 축 모두 양수.
- 시드 간 표준편차가 매우 작아(±2 수준) "시드 노이즈가 커서 로컬-실제 괴리를 만든다"는 애초 가설의 설명력은 약했지만, 배깅 자체는 그 작은 노이즈만큼 일관되게 개선.
- **사용자 요청으로 GroupKFold 확인 없이 바로 프로덕션 빌드**(`v18_seed_bagging/`, iterations=2000·전체데이터 3시드 학습·92분 소요) → 클린룸 검증 2단계 통과 → 실제 리더보드 제출.
- **결과: 979점(974.9 대비 +4.1)**. 로컬에서 예측한 delta(+4.34/+3.98)와 실제 delta(+4.1)가 **크기까지 거의 정확히 일치** — 이 프로젝트에서 로컬 신호가 방향뿐 아니라 크기까지 맞은 것은 확률보정(8/18)/raw id 도입(8/18)에 이은 세 번째이자 가장 정밀하게 들어맞은 사례. 새 정보를 추가하지 않는 순수 분산감소 방식이라 이 프로젝트의 반복된 "로컬개선→실제하락" 실패 메커니즘(새 정보의 시즌별 과적합)이 원천적으로 성립하지 않았던 것으로 해석.

## 3. Monotonic constraints — 기각, 두 축 다 뚜렷하게 악화
974 레시피 그대로, 상관계수로 방향이 명확한 asof_* 피처 8개(투수/타자 과거 성공률류 +1, reverse/middle rate류 -1)에 CatBoost `monotone_constraints`로 단조 제약.
- 결과(calibrated BSS): fold0 -36.87, fold2 -15.41. 두 축 다 악화, AUC 동반 하락.
- 원인 추정: 상관계수 부호는 명확했지만 트리가 국소적 비단조 상호작용(asof_n 구간별 신뢰도 차이 등)을 학습 중이었을 가능성 — 강제 제약이 표현력을 깎음. "CatBoost 네이티브 처리가 수동 개입보다 낫다"는 이 프로젝트의 반복 패턴과 같은 계열.

## 결론
- **팀 전체 최고 제출 갱신: 974.9(es_ws v7) → 979점(jh_ws v18_seed_bagging)**.
- 이번 재개 세션 3개 새 축(정규화/시드배깅/monotonic) 중 시드 배깅만 성공, 나머지 둘은 기각.
- 시드 배깅 성공은 "새 정보를 추가하지 않는 변경(순수 분산 감소)은 이 프로젝트의 로컬-실제 괴리 문제에서 예외적으로 자유로울 수 있다"는 가설을 실측으로 뒷받침 — 앞으로 유사한 "정보 무추가형" 개선(예: 시드 개수 확대)은 상대적으로 신뢰도 높은 후보로 취급 가능.
